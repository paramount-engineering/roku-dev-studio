Help & User Guide

Device Discovery

Click Scan to automatically discover Roku devices on your network. Devices with Developer Mode enabled will show a green "Dev" badge.

You can also manually connect by entering an IP address in the "Manual Connect" section at the bottom of the sidebar.

Scan finds nothing? SSDP multicast (UDP port 1900) may be blocked by VPN, corporate Wi‑Fi, or firewall rules — try Manual Connect with the device IP. The PC and Roku must be on the same reachable network.

Remote Control

Use the virtual remote to control your Roku. Optional keyboard shortcuts are available when you turn on Settings → General → Roku Remote - Use Keyboard (off by default). They apply on the Remote tab (solo or device-performance quad layout) or the Dev App tab, only for the device tab you have open — not in other sections, text fields, or modals.

Media controls (Rewind, Play/Pause, Forward) and volume buttons are also available on the virtual remote. Use Send Text at the bottom to type text directly into the device's active text field.

Apps

View all installed apps on your Roku device. Click any app to launch it. Use the search to filter apps by name.

  • Custom Launch - Launch any app by ID, including TV inputs (HDMI 1-4)
  • Deep Link - Launch apps with specific content using deep linking (App ID, Content ID, Media Type)
  • Raw List of Apps - View the raw XML list of all installed apps

Query

Query device information using Roku's ECP endpoints:

  • Device Queries - Presets for common queries like Device Info, Apps, Active App, Media Player, and more
  • Developer Queries - Advanced queries for dev-enabled devices (SG Nodes, Plugins, Frame Rate, Channel Perf, App State, Registry)
  • Custom Query - Enter any custom ECP endpoint

Results are displayed in the Results panel below. POST endpoints (SGRendezvous tracking, FW Beacons) are also available.

Dev App

For Developer Mode enabled devices:

  • Auth - Enter and validate your Roku Developer password. Enable "Remember" to persist it across sessions
  • Sideload - Install .zip or .pkg channel packages
  • Remote - View the device's web installer page for additional dev options
  • Screenshot - Capture screenshots from your running dev app
  • Delete - Remove the sideloaded channel

You'll need your Roku Developer password (set during Developer Mode setup).

Console

Connect to the BrightScript debug console via telnet (port 8085):

  • Connect / Disconnect - Establish or close the telnet connection
  • Find / Filter - Search through logs with options for case-sensitive, whole-word, and regex matching
  • Auto-scroll - Automatically scroll to the latest output
  • Copy / Save - Copy all logs to clipboard or save to a file
  • Clear - Clear the console output

Requires Developer Mode enabled. Only one telnet connection can be active at a time per device.

App Connector

Connect to Roku apps that implement the TrackerTask component for two-way communication:

  • Connect - Establishes a socket connection to your running dev app (default port 49200)
  • Execute Function - Call custom functions exposed by your scene's GetExternalControlFunctions
  • Response - View return values and debug output
  • Update Node - After running Get Node by ID, the response panel offers a node-update modal where you can selectNode, setField, or removeField on the matched node
  • RALE built-ins - The function dropdown also lists built-in RALE commands: Get Node by ID, Get Node by SubType, and a registry editor (Get All Sections, Add/Update Section, Remove Section, Set / Edit / Remove Section Key, Clear All Sections)

Your Roku app must have TrackerTask integrated. Click Integration Guide in the App Connector tab for the BrightScript snippets and supported parameter types. Use Save TrackerTask.xml from the same modal to drop a ready-to-ship copy into your channel.

Action Scripts

Automate sequences of device actions using JSON-based scripts. Two views are available:

Builder - Visually create action scripts action by action:

  • Action Types - Keypress, Send Text, Launch App, Device Query, POST, Sideload, Delete Sideload, Screenshot, App Function, RALE Command, Device Performance capture, Wait, If
  • Variables (script v2) - Use a Set Variable step or assignToVar on Device Query / App Function / RALE Command to remember values, then reference them as ${name} in later step fields (text, params, deep-link content, etc.)
  • If / Else if / Else (script v2) - Branch on conditions sourced from media-player state, the active app, a RALE node field, or a stored variable; nest If steps for multi-step branches
  • Wait conditions - Wait can be a fixed delayMs, or wait until a condition becomes true: media-player state or RALE node field (poll getNodeById and compare a field with operators like equals, contains, matches, hasAnyValue) with optional timeoutMs and pollIntervalMs
  • Device Performance step - Capture CPU, memory, objects, or all charts for the device this script runs on; the captured PNGs ship in run results / PDF export
  • Per-step help - The ? control on each builder row opens a context-aware help modal for that action type
  • Action Management - Add, delete, reorder (drag & drop), copy, and paste actions
  • Copy / Paste - Copy an action with the copy control on each row. After copying, use Paste Step next to any Add Step row to insert at that position, or Ctrl+V to append at the end of the script
  • Import - Load an existing script from a JSON file
  • Undo / Redo - Ctrl+Z to undo, Ctrl+Shift+Z to redo
  • JSON Preview - Live preview of the generated script. Copy or save the script to a file
  • Copy to Executor - Send the built script directly to the Executor for running

Executor - Import, validate, and run action scripts:

  • Import - Upload a JSON script file or paste script JSON, then validate
  • Run / Pause / Stop - Control execution with play, pause, and stop actions
  • Skip / Unskip - Toggle individual actions to skip during execution
  • Reorder - Drag and drop to reorder actions before running
  • Results - View detailed results for each action, including inline screenshots and captured performance charts
  • Copy / Save Results - Copy results to clipboard or save as PDF (PDF embeds screenshots and chart cards)
  • Connect to Console - Optionally auto-connect to the debug console during runs

Developer Password - Actions like Screenshot, Sideload, and Delete Sideload require a developer password. The password is resolved in order: action-level "password" → script-level "devPassword" → password from the Dev App Auth section. If none is found, you'll be prompted during validation.

Save Folder - The default save folder lives under Settings → Action Scripts → Default folder. Per run you can pick another folder. Artifacts (screenshots, performance chart PNGs, exported PDFs) land in a timestamped subfolder, created only when something is actually produced.

AI agents - Action Scripts you build in the Builder can also be authored by AI agents through the MCP server (see the AI Agents (MCP) section below); the agent's script always lands in the Builder for human review before running.

Device Performance (Remote tab)

Toggle Show Device Performance on the Remote tab to expand a quad with live charts:

  • CPU usage, system memory, and BrightScript object charts (count or memory view where available)
  • Charts reflect the running app — for representative readings, the device should have Developer Mode on and your sideloaded dev channel in the foreground
  • Settings → Device Performance tunes chart sample interval and history window; turn on Remember 'Show Device Performance' to restore the quad layout per device between sessions
  • Inside Action Scripts, Device Performance steps capture chart cards into run results (and PDF export)

Network Inspector

Inspect the HTTP(S) traffic your dev channel makes. Roku Dev Studio runs a local MITM proxy that decrypts dev-channel HTTPS routed through it, so you can see full request/response headers and bodies.

Getting started

  • Enable the MITM proxy in Settings → Network Inspector, then have your dev channel route its requests through the proxy address shown — use host:port (e.g. 192.168.1.50:8888). How the channel applies that proxy is up to your app's networking code.
  • Optional hotspot capture records SNI/DNS metadata for all of the device's traffic; it needs OS packet-capture access (macOS BPF, Windows Npcap). Settings → Network Inspector walks through the per-platform setup.

Toolbar (top-right of the panel): Start / Stop capture, panes layout (stack vs. side-by-side request/response), and Configure traffic rules.

  • Session list - Filter with host:, method:, status:, type:, kind:, path: (separate terms with commas for OR); group by host; toggle Proxied to hide hotspot-only metadata. Jump-to-error and scroll-to-latest shortcuts appear when relevant.
  • Inspect - View request / response overview, headers, and bodies (JSON / XML / raw). Copy a body, or export the transaction as cURL or HAR.
  • Save .pcap - Export the device's captured packets; Clear empties the session list.

Traffic Rules (the gear in the toolbar) shape this device's proxied traffic; changes take effect immediately:

  • Block all proxied traffic - Reject every proxied request. This wins over per-host rules and the device throttle.
  • Device throttle - Cap bandwidth and/or add latency for every proxied request. Pick a preset or type a custom value (e.g. 3 Mbps, 1500 kbps).
  • Per-host rules - Add a hostname to target every request to that host, or a host + path (e.g. api.example.com/v1/play) to target only that path. Each rule can Block, Reset the connection (simulate a network failure), Mock a canned response (status / content-type / delay / body), and/or throttle.
  • Bounds - A host can't be faster than the device's bandwidth cap, and its latency can't drop below the device latency floor.

Network Inspector is available for locally connected devices.

AI Agents (MCP)

Roku Dev Studio ships an MCP (Model Context Protocol) server so AI agents in Cursor, Claude Desktop, or VS Code can drive a real device through this app:

  • Settings → MCP Server - Toggle a client to add or remove its roku-dev-studio MCP entry; other entries in that client's MCP config are left untouched
  • Two surfaces - Direct device ops for one-shot actions (keypress, launch_app, screenshot, app_function, rale_command, telnet …) and Action Scripts for multi-step / conditional flows that drop into the Builder for review
  • Toasts - Destructive agent actions (launch, sideload, delete sideload, screenshot, destructive RALE commands) show a non-blocking toast in the app so you always see what the agent did
  • Passwords stay local - Sideload / screenshot / delete-sideload reuse the password the device panel remembered; the agent never has to send one

The bridge starts automatically when the app is open and shuts down on quit. If an agent reports the bridge is offline, just bring this app to the foreground.

BrightScript Fiddle

Open via File → Open Fiddle (Ctrl/Cmd+Shift+B) or the Open Fiddle button on the Query tab.

  • Editor - Monaco editor with BrightScript highlighting and live brighterscript linting; the Run button is disabled while errors are present
  • Run - Wraps your snippet into a minimal SceneGraph channel, sideloads it on the selected device, and streams the BrightScript debug console (8085) into the Fiddle window's terminal
  • Stop / window close - Removes the Fiddle channel from the device automatically

Requires a Developer Mode-enabled device with a known dev password (use the Dev App tab once to remember it, or you'll be prompted in Fiddle).

Log File Viewer

File → Open Log File (Ctrl/Cmd+Shift+O) opens a saved console / log file in a dedicated window with the same find / structured-log / URL-detection chrome as the live Console tab. Handy for reviewing logs from a previous session or a teammate.

Secret Screens

The Secret Screens link (Remote tab and the Query tab footer) opens a modal listing the standard Roku key sequences for hidden settings — Developer Settings, Secret Screen 1/2/3, Wi-Fi info, Channel Info, Reboot, etc. Click a sequence to send the keypresses to the connected device.

Settings

Open with Ctrl/Cmd+, or Roku Dev Studio → Settings (macOS) / File → Settings (Windows / Linux). Five sections:

  • General - Developer Mode, Privacy Mode (mask IPs / serials), Debug Logging to file, Roku Remote - Use Keyboard, Auto Connect to Devices, Auto Hide SideBar, Encrypt Saved Passwords (status line shows whether the OS keychain is really encrypting — on some Linux setups it is not)
  • Action Scripts - Default folder for run artifacts (screenshots, exported PDFs)
  • Device Performance - Chart sample interval, chart history window, Remember 'Show Device Performance' per device
  • Timing & Network - Connection / query / telnet timeouts and other network knobs (with Reset to Defaults)
  • MCP Server - Toggle roku-dev-studio in your AI client(s) so agents can drive the device through this app

Remote Locations

Control Roku devices at remote locations via a relay server:

  • Setup - Run the Roku Relay Server on a Mac Mini at the remote location
  • Add Location - Click "Add" in the Remote Locations section to configure a connection
  • Server Address - Enter the IP address or hostname of the relay server
  • Default Port - The relay server runs on port 4951 by default

The relay server can be found in the remote-server folder. See the README for setup instructions (macOS LaunchAgent, Linux systemd, Windows Task Scheduler).

Sideload or screenshot fails via relay but ECP works? Update the relay host to the same roku-dev-studio-api version as this app. Check GET /health on the relay (apiVersion field) and ensure port 4951 is reachable through firewalls.

Tips

  • Enable Developer Mode on your Roku: Go to Home, press Home 3x, ↑ 2x, → ← → ← →
  • Multiple devices can be connected simultaneously - each gets its own tab
  • Click a connected device card to switch to its tab
  • Right-click device cards to copy device info
  • Remote locations allow you to control devices without physical access
  • macOS: closing the main window quits the app (telnet and MCP sessions are torn down). Use Roku Dev Studio → Quit or Cmd+Q — the app does not stay in the dock with no windows.
  • Windows / Linux: use the title-bar menu (☰) for Settings, Privacy Mode, and About; window min/max/close buttons are on the right edge of the title bar.
