Keyboard Remote

Shortcuts apply while this device tab is on the Remote tab or the Dev App tab only.

Shortcuts mapped to Roku remote
Key Remote action
↑↓←→ Navigate (Up, Down, Left, Right)
Enter Select / OK
Backspace Back
Escape Home
Space Play / Pause
j Rewind
l Forward
* Options (Info)
r Instant Replay
+ Volume Increase
- Volume Decrease
m Mute
ShiftP Power

Turn Keyboard Remote off in Settings if you do not want arrow keys and other mapped keys to send Roku keypresses.
