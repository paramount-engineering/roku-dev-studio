Enable Developer Mode on Roku

What is Developer Mode?

Developer Mode allows you to sideload and test your own Roku channels directly on your device. It's free to enable and gives you access to powerful development tools.

Steps to Enable Developer Mode

  1. On your Roku remote, press: Home Home Home Up Up Right Left Right Left Right
  2. A Developer Settings dialog will appear on your TV
  3. Select "Enable installer and restart"
  4. Accept the Developer SDK License Agreement
  5. Set a Web Server Password (you'll need this for sideloading)
  6. Your Roku will restart with Developer Mode enabled

After Enabling

Once Developer Mode is enabled:

  • Your device will show a Dev badge in the device list
  • You can sideload .zip channel packages via the Dev App tab
  • Use the App Connector to communicate with your channel code
  • Access additional ECP queries in the Query tab
