Control by Mobile Apps on Roku

Why is this needed?

Remote functionality (keypress, apps, Quick Remote, Send Text) uses Roku's External Control Protocol (ECP). The device setting Control by Mobile Apps → Network Access can be set to one of four modes:

  • Disabled – Control by mobile apps is off.
  • Limited – Text input, app launches, and querying the active app only; enabled on private network addresses.
  • Permissive – Full control; accepts commands only from private network or the same subnet.
  • Enabled – Full control; enabled on private network addresses.

How to change the setting

  1. On your Roku device, go to Settings → System
  2. Open Advanced System Settings
  3. Select Control by Mobile Apps
  4. Select Network Access
  5. Choose Limited, Permissive, or Enabled (this app adapts to the mode)

After changing

With Limited, Send Text, app launch, and app query work; full remote keypress may not. With Permissive or Enabled, full remote control works. For Permissive, ensure this computer is on the same subnet as the Roku if commands fail. No restart is required after changing the setting.
