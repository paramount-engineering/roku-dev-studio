System view — System memory consumed by the running app.

UsedTotal memory used by the app process — the sum of Resident and Swap.
ResidentMemory mapped into the app’s address space: anonymous, file-backed, and shared memory combined.
AnonymousMemory such as the stack and heap; also includes the demux allocation during media playback.
SharedShared memory used by the app process, e.g. media player buffers and IPC channels.
LimitThe device’s foreground memory limit — exceeding it while the app is in the foreground can get the app terminated.
