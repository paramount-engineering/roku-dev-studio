Integration Guide

What is TrackerTask?

TrackerTask is a BrightScript component originally created for RALE (Roku Advanced Layout Editor) - Roku's official developer tool for inspecting and debugging SceneGraph applications in real-time.

The TrackerTask establishes a socket connection between your Roku app and external tools, enabling:

  • Real-time node inspection and modification
  • Live view of UI element boundaries
  • Registry management
  • Logging and debugging

The App Connector extends this functionality with two custom functions that allow you to expose and execute your app's custom BrightScript functions from this desktop tool.

Custom Functions for App Connector

Two functions have been added to the TrackerTask to enable the App Connector functionality:

UIThread_getExternalControlFunctions BrightScript
' Retrieves list of available functions from your app's Scene Function UIThread_getExternalControlFunctions(args) as Object root = m.top.getScene() if (root <> invalid) then funcList = root.callFunc("GetExternalControlFunctions", invalid) if (funcList <> invalid and type(funcList) = "roArray") then return { success: true, functions: funcList } end if end if return { success: false } End Function
UIThread_executeExternalControlFunction BrightScript
' Executes a function on your app's Scene with provided parameters Function UIThread_executeExternalControlFunction(args) as Object opResult = { success: false } if ((GetInterface(args, "ifAssociativeArray") <> invalid) and (not args.IsEmpty())) then if FW_IsString(args.functionName) then root = m.top.getScene() if (root <> invalid) then funcResult = root.callFunc("ExecuteFunction", args.functionName, args.functionParams) opResult = { success: true, result: funcResult } end if end if end if return opResult End Function

Implementing in Your Scene

Your app's MainScene.xml must declare two interface functions that the TrackerTask will call:

MainScene.xml XML
<component name="MainScene" extends="Scene"> <interface> <!-- Required for App Connector --> <function name="GetExternalControlFunctions" /> <function name="ExecuteFunction" /> </interface> <script type="text/brightscript" uri="MainScene.brs" /> </component>

GetExternalControlFunctions Implementation

This function must return an roArray of associative arrays, where each item describes a function:

MainScene.brs BrightScript
Function GetExternalControlFunctions(args) as Object return [ { name: "PlayContent", description: "Plays video content by ID", params: [ { name: "contentId", type: "String" }, { name: "autoPlay", type: "Boolean" } ] }, { name: "SetUserPreferences", description: "Updates user preferences", params: [ { name: "preferences", type: "roAssociativeArray" } ] }, { name: "GetAppState", description: "Returns current application state", params: [] }, { name: "NavigateToScreen", description: "Navigate to a specific screen", params: [ { name: "screenName", type: "String" }, { name: "screenParams", type: "roAssociativeArray" } ] } ] End Function
📝 Supported Parameter Types

Boolean · Integer · LongInteger · Float · Double · String · roAssociativeArray · roArray · roList

ExecuteFunction Implementation

This function receives the function name and parameters array, then routes to the appropriate handler:

MainScene.brs BrightScript
Function ExecuteFunction(functionName as String, params as Object) as Object result = invalid if functionName = "PlayContent" then contentId = params[0] ' String autoPlay = params[1] ' Boolean result = PlayContent(contentId, autoPlay) else if functionName = "SetUserPreferences" then preferences = params[0] ' roAssociativeArray result = SetUserPreferences(preferences) else if functionName = "GetAppState" then result = GetAppState() else if functionName = "NavigateToScreen" then screenName = params[0] ' String screenParams = params[1] ' roAssociativeArray result = NavigateToScreen(screenName, screenParams) end if return result End Function ' Example handler implementations Function PlayContent(contentId as String, autoPlay as Boolean) as Object ' Your implementation here return { success: true, message: "Playing: " + contentId } End Function

TrackerTask Setup

Add the TrackerTask component to your project and create an instance in your MainScene:

MainScene.brs (init) BrightScript
Sub init() ' Initialize TrackerTask for App Connector m.trackerTask = CreateObject("roSGNode", "TrackerTask") m.trackerTask.control = "run" ' Your other initialization code... End Sub

Place the TrackerTask.xml file in your App's components/ directory.
